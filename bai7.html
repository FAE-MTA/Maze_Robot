Bài 7. Hiển thị với OLED

Khởi tạo màn hình OLED I2C, trình bày dữ liệu cảm biến và xây dựng giao diện debug ngắn gọn cho robot.

1. Mục tiêu bài học

  • Kết nối đúng OLED với bus I2C của Mega 2560.
  • Khởi tạo màn hình SSD1306 địa chỉ 0x3C và phát hiện lỗi khởi tạo.
  • Hiển thị chữ, số và trạng thái mà không làm chậm vòng điều khiển.
  • Kết hợp OLED với Serial Monitor để debug robot.

2. Kiến thức trọng tâm

I2C sử dụng hai đường tín hiệu: SDA truyền dữ liệu và SCL truyền xung nhịp. Trên Mega 2560, SDA là D20 và SCL là D21. Nhiều thiết bị có thể dùng chung hai dây nếu địa chỉ I2C không trùng nhau.

OLED 128×64 không tự hiển thị ngay sau lệnh vẽ. Các lệnh chỉ thay đổi bộ đệm RAM; phải gọi display.display() để gửi toàn bộ bộ đệm lên màn hình.

Không nên xóa và cập nhật OLED ở mọi vòng lặp rất nhanh. Chu kỳ 100–250 ms đủ để quan sát và giúp thuật toán chuyển động chạy ổn định hơn.

4. Chương trình thực hành

Chương trình dưới đây được viết đầy đủ, có chú thích tiếng Việt và có thể mở trực tiếp trong Arduino IDE.

Bài 7 – OLED hiển thị bộ đếm và trạng thái
// BÀI 7: HIỂN THỊ OLED 128x64 QUA I2C
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

const uint8_t DIA_CHI_OLED = 0x3C;
const int CHIEU_RONG = 128;
const int CHIEU_CAO = 64;

Adafruit_SSD1306 oled(CHIEU_RONG, CHIEU_CAO, &Wire, -1);
unsigned long lanCapNhatCuoi = 0;
unsigned long boDem = 0;

void hienThiTrangThai(const char *trangThai) {
  oled.clearDisplay();
  oled.setTextColor(SSD1306_WHITE);

  oled.setTextSize(1);
  oled.setCursor(0, 0);
  oled.println("ROBOT MEGA 2560");
  oled.drawLine(0, 11, 127, 11, SSD1306_WHITE);

  oled.setCursor(0, 20);
  oled.print("Trang thai: ");
  oled.println(trangThai);

  oled.setCursor(0, 36);
  oled.print("Thoi gian: ");
  oled.print(millis() / 1000.0, 1);
  oled.println(" s");

  oled.setCursor(0, 50);
  oled.print("So lan: ");
  oled.println(boDem);

  // Gửi bộ đệm lên màn hình.
  oled.display();
}

void setup() {
  Serial.begin(115200);
  Wire.begin();

  if (!oled.begin(SSD1306_SWITCHCAPVCC, DIA_CHI_OLED)) {
    Serial.println("LOI: KHONG TIM THAY OLED");
    while (true) {
      delay(1000); // Dừng an toàn để chờ kiểm tra phần cứng.
    }
  }

  oled.clearDisplay();
  oled.display();
  hienThiTrangThai("KHOI DONG");
  Serial.println("OLED DA SAN SANG");
}

void loop() {
  // Chỉ làm mới màn hình mỗi 200 ms.
  if (millis() - lanCapNhatCuoi >= 200) {
    lanCapNhatCuoi = millis();
    boDem++;
    hienThiTrangThai("DANG CHAY");

    Serial.print("Bo dem = ");
    Serial.println(boDem);
  }
}

5. Phân tích chương trình và thuật toán

  • Wire.begin() khởi tạo bus I2C; oled.begin() kiểm tra màn hình tại địa chỉ 0x3C.
  • Hàm hienThiTrangThai() gom toàn bộ thao tác trình bày vào một nơi, giúp các bài sau chỉ cần truyền trạng thái cần hiển thị.
  • Điều kiện dựa trên millis() thay cho delay(), vì vậy vòng lặp vẫn có thể đọc cảm biến và điều khiển động cơ.
  • Serial được giữ song song để vẫn quan sát được lỗi khi OLED không khởi tạo.

6. Quy trình thực hành

  1. Cài Adafruit GFX Library và Adafruit SSD1306 trong Library Manager.
  2. Đấu SDA vào D20, SCL vào D21, sau đó nạp chương trình.
  3. Quan sát dòng trạng thái, thời gian và bộ đếm trên OLED; đối chiếu bộ đếm trên Serial Monitor.
  4. Thử tăng chu kỳ cập nhật từ 200 ms lên 500 ms và nhận xét độ mượt của hiển thị.

7. Bài tập củng cố và mở rộng

  1. Tạo hàm hiển thị ba khoảng cách trái, trước và phải.
  2. Vẽ thanh biểu diễn giá trị PWM từ 0 đến 255 bằng fillRect().
  3. Chỉ cập nhật vùng số thay đổi và so sánh tốc độ với cách xóa toàn màn hình.

8. Lỗi thường gặp và cách xử lý

OLED không sáng: kiểm tra địa chỉ 0x3C, nguồn, SDA D20 và SCL D21.
Chương trình báo thiếu tệp thư viện: cài Adafruit GFX và Adafruit SSD1306, sau đó khởi động lại Arduino IDE.
Màn hình nhấp nháy: giảm tần suất clearDisplay() và display().
OLED khởi động chậm: tránh ảnh splash lớn và chỉ hiển thị màn hình chào trong thời gian ngắn.

9. Kết luận

OLED trở thành công cụ quan sát tại chỗ, còn Serial cung cấp dữ liệu chi tiết cho máy tính. Từ Bài 8 trở đi, hai kênh này được sử dụng đồng thời.
