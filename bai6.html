Bài 6. Điều khiển động cơ DC

Tìm hiểu cầu H, điều khiển chiều quay và tốc độ hai bánh để tạo các chuyển động tiến, lùi, quay trái, quay phải và dừng an toàn.

1. Mục tiêu bài học

  • Giải thích được vì sao không cấp động cơ trực tiếp từ chân Arduino.
  • Điều khiển đúng chiều và tốc độ của từng động cơ bằng bốn chân PWM.
  • Xây dựng các hàm chuyển động cơ bản để tái sử dụng ở những bài sau.
  • Thực hiện đúng quy trình thử động cơ an toàn khi bánh xe được kê khỏi mặt đất.

2. Kiến thức trọng tâm

Động cơ DC cần dòng điện lớn và tạo nhiễu điện, vì vậy Arduino chỉ phát tín hiệu điều khiển tới mạch cầu H. Trên robot, mỗi động cơ dùng hai chân PWM: đặt PWM vào một chân và giữ chân còn lại bằng 0 để chọn chiều quay.

Giá trị PWM nằm trong khoảng 0–255. PWM càng lớn thì điện áp trung bình cấp cho động cơ càng cao. Hai động cơ được lắp đối xứng nên cùng một lệnh điện có thể làm hai bánh quay theo hai chiều cơ khí khác nhau; chương trình phải đảo chiều động cơ phải.

Quy ước của bài: tốc độ dương làm robot tiến, tốc độ âm làm robot lùi, tốc độ bằng 0 làm động cơ dừng.

4. Chương trình thực hành

Chương trình dưới đây được viết đầy đủ, có chú thích tiếng Việt và có thể mở trực tiếp trong Arduino IDE.

Bài 6 – kiểm tra tiến, lùi, trái, phải
// BÀI 6: ĐIỀU KHIỂN HAI ĐỘNG CƠ DC
// Bo mạch: Arduino Mega 2560 Mini

const uint8_t MOTOR_TRAI_A = 5;
const uint8_t MOTOR_TRAI_B = 9;
const uint8_t MOTOR_PHAI_A = 6;
const uint8_t MOTOR_PHAI_B = 10;

// Điều khiển một động cơ bằng tốc độ có dấu.
// tocDo > 0: quay thuận; tocDo < 0: quay ngược; tocDo = 0: dừng.
void datMotDongCo(uint8_t chanA, uint8_t chanB,
                 int tocDo, bool daoChieu) {
  tocDo = constrain(tocDo, -255, 255);
  if (daoChieu) tocDo = -tocDo;

  if (tocDo > 0) {
    analogWrite(chanA, tocDo);
    analogWrite(chanB, 0);
  } else if (tocDo < 0) {
    analogWrite(chanA, 0);
    analogWrite(chanB, -tocDo);
  } else {
    analogWrite(chanA, 0);
    analogWrite(chanB, 0);
  }
}

void datHaiDongCo(int tocDoTrai, int tocDoPhai) {
  datMotDongCo(MOTOR_TRAI_A, MOTOR_TRAI_B, tocDoTrai, false);
  datMotDongCo(MOTOR_PHAI_A, MOTOR_PHAI_B, tocDoPhai, true);
}

void diThang(int pwm)  { datHaiDongCo( pwm,  pwm); }
void diLui(int pwm)    { datHaiDongCo(-pwm, -pwm); }
void quayTrai(int pwm) { datHaiDongCo(-pwm,  pwm); }
void quayPhai(int pwm) { datHaiDongCo( pwm, -pwm); }
void dungRobot()       { datHaiDongCo(0, 0); }

void chayTrongThoiGian(const char *tenLenh,
                       void (*hamChuyenDong)(int),
                       int pwm, unsigned long thoiGianMs) {
  Serial.println(tenLenh);
  hamChuyenDong(pwm);
  delay(thoiGianMs);
  dungRobot();
  delay(800);
}

void setup() {
  Serial.begin(115200);
  pinMode(MOTOR_TRAI_A, OUTPUT);
  pinMode(MOTOR_TRAI_B, OUTPUT);
  pinMode(MOTOR_PHAI_A, OUTPUT);
  pinMode(MOTOR_PHAI_B, OUTPUT);
  dungRobot();
  Serial.println("BAT DAU BAI 6");
  delay(2000);
}

void loop() {
  chayTrongThoiGian("TIEN",  diThang,  120, 1500);
  chayTrongThoiGian("LUI",   diLui,    120, 1500);
  chayTrongThoiGian("TRAI",  quayTrai, 110, 700);
  chayTrongThoiGian("PHAI",  quayPhai, 110, 700);

  Serial.println("KET THUC CHU KY\n");
  delay(2500);
}

5. Phân tích chương trình và thuật toán

  • Hàm datMotDongCo() giới hạn tốc độ và biến tốc độ có dấu thành hai tín hiệu PWM cho cầu H.
  • Tham số daoChieu xử lý việc hai động cơ được lắp đối xứng; không cần đảo dây trong từng thuật toán.
  • Các hàm diThang(), diLui(), quayTrai() và quayPhai() là lớp lệnh chuyển động dùng lại ở Bài 14–17.
  • Robot luôn gọi dungRobot() sau mỗi phép thử để tránh chuyển hướng đột ngột.

6. Quy trình thực hành

  1. Kê hai bánh chủ động khỏi mặt bàn, kiểm tra nguồn và GND chung.
  2. Nạp chương trình, mở Serial Monitor ở 115200 baud và quan sát từng lệnh.
  3. Kiểm tra cả hai bánh tạo đúng chuyển động tiến. Nếu chỉ một bánh ngược, sửa đúng biến daoChieu của bánh đó.
  4. Hạ robot xuống sàn, thử lại với PWM 80–120 trước khi tăng tốc.

7. Bài tập củng cố và mở rộng

  1. Viết thêm hàm rẽ cong bằng cách đặt hai bánh cùng chiều nhưng khác tốc độ.
  2. Thay delay() bằng bộ định thời millis() để chương trình vẫn đọc được cảm biến khi đang chạy.
  3. Đo PWM nhỏ nhất làm từng bánh bắt đầu quay và ghi kết quả vào bảng thực hành.

8. Lỗi thường gặp và cách xử lý

Robot không chạy: kiểm tra nguồn động cơ, công tắc nguồn và dây GND chung.
Một bánh quay ngược: chỉ đổi cờ đảo chiều của đúng động cơ; không đảo đồng thời cả phần cứng lẫn phần mềm.
Mega 2560 bị reset khi động cơ khởi động: nguồn yếu hoặc nhiễu động cơ; tách nguồn công suất và kiểm tra tụ lọc.
Bánh quay quá nhanh khi kê lên: giảm PWM trước khi đặt robot xuống sàn.

9. Kết luận

Sau bài học, sinh viên đã có bộ hàm chuyển động cơ bản và quy ước chiều thống nhất. Đây là nền tảng để điều khiển theo encoder, bám line và tránh vật cản.
