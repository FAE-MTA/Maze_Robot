BÀI GIẢNG LẬP TRÌNH ROBOT MÊ CUNG

Bài 11. Cảm biến màu TCS3200

Đo tần số ba kênh đỏ–lục–lam, hiệu chỉnh theo môi trường và nhận dạng màu của khối ở khoảng cách phù hợp.

1. Mục tiêu bài học

  • Hiểu quan hệ giữa bộ lọc màu S2/S3 và xung OUT của TCS3200.
  • Đo được độ rộng xung R, G, B với timeout để tránh treo chương trình.
  • Phát hiện trường hợp không có xung và không gán nhầm thành một màu.
  • Hiệu chỉnh khoảng cách, ánh sáng và ngưỡng phân loại trên robot thật.

2. Kiến thức trọng tâm

TCS3200 gồm ma trận photodiode và bộ chuyển đổi ánh sáng–tần số. Hai chân S2, S3 chọn bộ lọc đỏ, lục, lam hoặc không lọc. Tần số OUT càng cao khi cường độ ánh sáng của kênh đang chọn càng mạnh.

Chương trình đo độ rộng xung LOW, vì vậy số đo thường biến thiên ngược với cường độ: xung nhỏ hơn có nghĩa kênh màu mạnh hơn. Không dùng một bộ ngưỡng cho mọi robot; cần thu mẫu với chính đèn, vỏ che và khoảng cách làm việc thực tế.

Khoảng cách khởi đầu nên thử là 1–3 cm. Đèn LED D26 phải bật ổn định và cảm biến nên được che bớt ánh sáng ngoài.

4. Chương trình thực hành

Chương trình dưới đây được viết đầy đủ, có chú thích tiếng Việt và có thể mở trực tiếp trong Arduino IDE.

Bài 11 – đọc RGB và phân loại màu cơ bản
// BÀI 11: CẢM BIẾN MÀU TCS3200
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

const uint8_t S0_PIN = 25;
const uint8_t S1_PIN = 24;
const uint8_t LED_PIN = 26;
const uint8_t OUT_PIN = 29;
const uint8_t S2_PIN = 28;
const uint8_t S3_PIN = 27;

const unsigned long TIMEOUT_NHANH_US = 30000UL;
const unsigned long TIMEOUT_CHAM_US = 100000UL;

Adafruit_SSD1306 oled(128, 64, &Wire, -1);

unsigned long docMotKenh(uint8_t s2, uint8_t s3) {
  digitalWrite(S2_PIN, s2);
  digitalWrite(S3_PIN, s3);
  delay(3); // Chờ bộ lọc quang ổn định.

  unsigned long xung = pulseIn(OUT_PIN, LOW, TIMEOUT_NHANH_US);
  if (xung == 0) {
    // Thử lại với thời gian chờ dài hơn khi bề mặt tối.
    xung = pulseIn(OUT_PIN, LOW, TIMEOUT_CHAM_US);
  }
  return xung;
}

const char *nhanDangMau(unsigned long r,
                        unsigned long g,
                        unsigned long b) {
  if (r == 0 || g == 0 || b == 0) return "NO PULSE";

  // Độ rộng xung nhỏ hơn nghĩa là kênh màu mạnh hơn.
  if (r * 100UL < g * 85UL && r * 100UL < b * 85UL) return "DO";
  if (g * 100UL < r * 85UL && g * 100UL < b * 85UL) return "XANH LA";
  if (b * 100UL < r * 85UL && b * 100UL < g * 85UL) return "XANH DUONG";
  return "CHUA RO";
}

void hienThi(unsigned long r, unsigned long g,
             unsigned long b, const char *mau) {
  oled.clearDisplay();
  oled.setTextColor(SSD1306_WHITE);
  oled.setTextSize(1);
  oled.setCursor(0, 0);
  oled.println("TCS3200 - XUNG us");
  oled.setCursor(0, 16); oled.print("R: "); r ? oled.println(r) : oled.println("--");
  oled.setCursor(0, 28); oled.print("G: "); g ? oled.println(g) : oled.println("--");
  oled.setCursor(0, 40); oled.print("B: "); b ? oled.println(b) : oled.println("--");
  oled.setCursor(0, 53); oled.print("MAU: "); oled.println(mau);
  oled.display();
}

void setup() {
  Serial.begin(115200);
  pinMode(S0_PIN, OUTPUT);
  pinMode(S1_PIN, OUTPUT);
  pinMode(S2_PIN, OUTPUT);
  pinMode(S3_PIN, OUTPUT);
  pinMode(LED_PIN, OUTPUT);
  pinMode(OUT_PIN, INPUT);

  // Chọn tỉ lệ tần số đầu ra 20%.
  digitalWrite(S0_PIN, HIGH);
  digitalWrite(S1_PIN, LOW);
  digitalWrite(LED_PIN, HIGH);

  Wire.begin();
  if (!oled.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("LOI OLED");
    while (true) delay(1000);
  }
}

void loop() {
  unsigned long r = docMotKenh(LOW, LOW);   // Bộ lọc đỏ
  unsigned long b = docMotKenh(LOW, HIGH);  // Bộ lọc lam
  unsigned long g = docMotKenh(HIGH, HIGH); // Bộ lọc lục
  const char *mau = nhanDangMau(r, g, b);

  Serial.print("R="); Serial.print(r);
  Serial.print(" G="); Serial.print(g);
  Serial.print(" B="); Serial.print(b);
  Serial.print(" MAU="); Serial.println(mau);

  hienThi(r, g, b, mau);
  delay(150);
}

5. Phân tích chương trình và thuật toán

  • S0 HIGH và S1 LOW chọn tần số đầu ra 20%, phù hợp để pulseIn() đo ổn định.
  • Mỗi kênh được thử với hai mức timeout; kết quả 0 vẫn được giữ là lỗi NO PULSE, không thay bằng một số giả.
  • Phép so sánh theo tỉ lệ 85% yêu cầu một kênh trội rõ ràng, hạn chế phân loại khi màu xám hoặc tín hiệu gần bằng nhau.
  • Thuật toán chỉ là điểm khởi đầu; ngưỡng phải được thay bằng dữ liệu hiệu chỉnh của các khối màu thi đấu.

6. Quy trình thực hành

  1. Đặt bề mặt trắng cách cảm biến khoảng 2 cm và xác nhận cả ba kênh đều có xung.
  2. Đưa lần lượt khối đỏ, xanh lá, xanh dương vào cùng vị trí; ghi ít nhất 20 bộ R/G/B cho mỗi màu.
  3. Kiểm tra kênh có xung nhỏ nhất đối với từng màu và điều chỉnh tỉ lệ 85% nếu cần.
  4. Thử thay đổi khoảng cách ±1 cm để xác định vùng làm việc ổn định.

7. Bài tập củng cố và mở rộng

  1. Tính giá trị chuẩn hóa R/(R+G+B), G/(R+G+B), B/(R+G+B) và so sánh độ ổn định.
  2. Bổ sung nhận dạng màu trắng và màu đen dựa trên tổng cường độ.
  3. Lấy trung vị 5 lần đo cho từng kênh trước khi phân loại.

8. Lỗi thường gặp và cách xử lý

Một kênh luôn --: kiểm tra D29, dây OUT, nguồn cảm biến và chân chọn bộ lọc D27/D28.
Không có vật xanh nhưng kênh G báo --: đây là mất xung, không phải giá trị màu; tăng timeout và kiểm tra khoảng cách, đèn D26.
Màu thay đổi theo ánh sáng phòng: dùng vỏ che và đèn chiếu cố định.
Nhận màu ngược: nhớ rằng chương trình đang đo độ rộng xung nên giá trị nhỏ hơn thường biểu thị kênh mạnh hơn.

9. Kết luận

Sinh viên đã biết đo tín hiệu tần số, xử lý trường hợp không có xung và xây dựng bộ phân loại dựa trên dữ liệu thực nghiệm thay vì phỏng đoán.
