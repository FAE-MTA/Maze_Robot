Bài 8. Cảm biến siêu âm HC-SR04 phía trước

Đo khoảng cách vật cản phía trước bằng HC-SR04 với Trigger D4, Echo D7 và xử lý an toàn khi không nhận được xung Echo.

1. Mục tiêu bài học

  • Tạo đúng xung Trigger 10 µs và đo độ rộng xung Echo.
  • Đổi thời gian truyền–nhận thành khoảng cách centimet.
  • Phân biệt rõ vật cản với trạng thái NO ECHO.
  • Hiển thị kết quả đồng thời trên OLED và Serial Monitor.

2. Kiến thức trọng tâm

HC-SR04 phát sóng siêu âm và đo thời gian sóng phản xạ quay về. Khoảng cách được tính theo công thức d = t × 0,0343 / 2, trong đó t tính bằng micro giây.

Cấu hình mới nhất chỉ dùng một cảm biến phía trước. Hai hướng trái và phải được đo bằng VL53L0X ở Bài 9, không dùng thêm hai chân Echo như phiên bản sơ đồ cũ.

Hàm pulseIn() luôn có timeout. Kết quả 0 được báo là NO ECHO, không tự biến thành một khoảng cách hợp lệ.

4. Chương trình thực hành

Mã ví dụ sử dụng đúng cấu hình đã kiểm tra trên robot, có OLED và Serial để quan sát.

Bài 8 – đo khoảng cách phía trước
// BÀI 8: CẢM BIẾN SIÊU ÂM PHÍA TRƯỚC
// Cấu hình đã kiểm tra: TRIG D4, ECHO D7.
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

const uint8_t TRIG_PIN = 4;
const uint8_t ECHO_PIN = 7;
const unsigned long TIMEOUT_US = 30000UL;

Adafruit_SSD1306 oled(128, 64, &Wire, -1);

bool docKhoangCach(float &khoangCachCm) {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  unsigned long thoiGianUs = pulseIn(ECHO_PIN, HIGH, TIMEOUT_US);
  if (thoiGianUs == 0) {
    khoangCachCm = -1.0f;
    return false;
  }

  khoangCachCm = thoiGianUs * 0.0343f / 2.0f;
  return khoangCachCm >= 2.0f && khoangCachCm <= 400.0f;
}

void hienThi(bool hopLe, float cm) {
  oled.clearDisplay();
  oled.drawRect(0, 0, 128, 64, SSD1306_WHITE);
  oled.setTextColor(SSD1306_WHITE);
  oled.setTextSize(1);
  oled.setCursor(8, 5);
  oled.println(F("SIEU AM PHIA TRUOC"));
  oled.drawLine(0, 17, 127, 17, SSD1306_WHITE);

  if (hopLe) {
    oled.setTextSize(3);
    oled.setCursor(5, 28);
    oled.print(cm, 1);
    oled.setTextSize(1);
    oled.print(F(" cm"));
  } else {
    oled.setTextSize(2);
    oled.setCursor(18, 31);
    oled.println(F("NO ECHO"));
  }
  oled.display();
}

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  digitalWrite(TRIG_PIN, LOW);

  Wire.begin();
  if (!oled.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println(F("LOI OLED 0x3C"));
    while (true) delay(1000);
  }
}

void loop() {
  float khoangCachCm;
  bool hopLe = docKhoangCach(khoangCachCm);

  Serial.print(F("Truoc: "));
  if (hopLe) {
    Serial.print(khoangCachCm, 1);
    Serial.println(F(" cm"));
  } else {
    Serial.println(F("NO ECHO"));
  }

  hienThi(hopLe, khoangCachCm);
  delay(200);
}

5. Phân tích chương trình

  • Trigger D4 được giữ LOW trước và sau xung HIGH 10 µs.
  • Timeout 30 ms ngăn chương trình treo khi mất Echo D7.
  • Hàm trả cả cờ hợp lệ và giá trị khoảng cách để thuật toán sau không nhầm lỗi với đường trống.
  • OLED và Serial dùng chung kết quả của một lần đo.

6. Quy trình thực hành

  1. Đặt vật phẳng cách cảm biến 10, 20, 40 cm và đối chiếu bằng thước.
  2. Rút riêng dây Echo D7 để xác nhận chương trình báo NO ECHO.
  3. Thử các vật có góc nghiêng và ghi nhận trường hợp phản xạ yếu.
  4. Chọn ngưỡng vật cản ban đầu khoảng 20–25 cm cho các bài di chuyển.

7. Bài tập mở rộng

  1. Lấy trung vị ba phép đo để loại nhiễu.
  2. Bật cảnh báo khi khoảng cách nhỏ hơn 25 cm.
  3. Đo thời gian xử lý tối đa khi mất Echo.

8. Lỗi thường gặp và cách xử lý

Luôn NO ECHO: kiểm tra đúng TRIG D4, ECHO D7, nguồn và GND.
Giá trị dao động: dùng mặt phản xạ lớn, đặt vuông góc và lọc nhiều mẫu.
Không dùng sơ đồ cũ có Echo D8/D11 cho robot cấu hình mới.

9. Kết luận

Robot đã đo được khoảng cách phía trước bằng đúng một HC-SR04. Bài 9 bổ sung hai khoảng cách bên bằng laser.
