Bài 12. Điều khiển vòng LED NeoPixel

Điều khiển 12 LED WS2812 qua một chân dữ liệu D13, tạo màu trạng thái và kiểm tra riêng từng điểm sáng.

1. Mục tiêu bài học

  • Khởi tạo đúng vòng 12 LED NeoPixel trên D13.
  • Tạo màu từ ba thành phần RGB và điều chỉnh độ sáng toàn vòng.
  • Kiểm tra lần lượt từng LED để tìm lỗi nguồn hoặc lỗi truyền chuỗi.
  • Dùng màu LED làm tín hiệu trạng thái robot.

2. Kiến thức trọng tâm

NeoPixel tích hợp mạch điều khiển trong từng LED và truyền dữ liệu nối tiếp qua một dây. Sau khi ghi màu vào bộ đệm, phải gọi pixels.show() để gửi dữ liệu tới vòng LED.

Toàn bộ 12 LED sáng trắng ở mức cao có thể tiêu thụ dòng lớn. Bài thực hành giới hạn độ sáng và dùng màu trắng ở mức thấp để bảo vệ nguồn.

NeoPixel tạm khóa ngắt trong thời gian gửi dữ liệu. Không gọi show() liên tục không cần thiết, đặc biệt khi servo hoặc encoder đang hoạt động.

4. Chương trình thực hành

Mã ví dụ sử dụng đúng cấu hình đã kiểm tra trên robot, có OLED và Serial để quan sát.

Bài 12 – thử màu và quét từng LED
// BÀI 12: ĐIỀU KHIỂN VÒNG LED NEOPIXEL
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <Adafruit_NeoPixel.h>

const uint8_t PIXEL_PIN = 13;
const uint8_t PIXEL_COUNT = 12;
const uint8_t DO_SANG = 150;

Adafruit_NeoPixel pixels(PIXEL_COUNT, PIXEL_PIN,
                         NEO_GRB + NEO_KHZ800);
Adafruit_SSD1306 oled(128, 64, &Wire, -1);

void datTatCaLed(uint8_t red, uint8_t green, uint8_t blue) {
  uint32_t mau = pixels.Color(red, green, blue);
  for (uint8_t i = 0; i < PIXEL_COUNT; i++) {
    pixels.setPixelColor(i, mau);
  }
  pixels.show();
}

void hienThiMau(const __FlashStringHelper *ten,
                uint8_t r, uint8_t g, uint8_t b) {
  oled.clearDisplay();
  oled.drawRect(0, 0, 128, 64, SSD1306_WHITE);
  oled.setTextColor(SSD1306_WHITE);
  oled.setTextSize(1);
  oled.setCursor(8, 4); oled.println(F("VONG LED NEOPIXEL"));
  oled.drawLine(0, 16, 127, 16, SSD1306_WHITE);
  oled.setCursor(4, 23); oled.print(F("MAU: ")); oled.println(ten);
  oled.setCursor(4, 38); oled.print(F("R:")); oled.print(r);
  oled.print(F(" G:")); oled.print(g);
  oled.print(F(" B:")); oled.println(b);
  oled.setCursor(4, 53); oled.print(F("DATA D13 - 12 LED"));
  oled.display();
}

void chayMau(const __FlashStringHelper *ten,
             uint8_t r, uint8_t g, uint8_t b) {
  datTatCaLed(r, g, b);
  hienThiMau(ten, r, g, b);
  Serial.print(F("Mau: ")); Serial.println(ten);
  delay(1000);
}

void quetTungLed() {
  for (uint8_t i = 0; i < PIXEL_COUNT; i++) {
    pixels.clear();
    pixels.setPixelColor(i, pixels.Color(255, 0, 0));
    pixels.show();

    oled.clearDisplay();
    oled.setTextColor(SSD1306_WHITE);
    oled.setTextSize(1);
    oled.setCursor(8, 5); oled.println(F("KIEM TRA TUNG LED"));
    oled.setTextSize(2);
    oled.setCursor(20, 27); oled.print(F("LED "));
    oled.print(i + 1); oled.print('/'); oled.print(PIXEL_COUNT);
    oled.display();
    delay(120);
  }
  pixels.clear();
  pixels.show();
}

void setup() {
  Serial.begin(115200);
  Wire.begin();
  if (!oled.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println(F("LOI OLED 0x3C"));
    while (true) delay(1000);
  }

  pixels.begin();
  pixels.setBrightness(DO_SANG);
  pixels.clear();
  pixels.show();
  Serial.println(F("NeoPixel D13, 12 LED"));
  quetTungLed();
}

void loop() {
  chayMau(F("DO"), 255, 0, 0);
  chayMau(F("XANH LA"), 0, 255, 0);
  chayMau(F("XANH DUONG"), 0, 0, 255);
  chayMau(F("TRANG THAP"), 60, 60, 60);
  chayMau(F("TAT"), 0, 0, 0);
  quetTungLed();
}

5. Phân tích chương trình

  • setBrightness() giới hạn độ sáng toàn vòng trước khi gửi dữ liệu.
  • Hàm datTatCaLed() ghi đủ 12 vị trí rồi mới gọi show() một lần.
  • Quét từng điểm giúp phát hiện LED đầu tiên hỏng làm các LED phía sau mất dữ liệu.
  • OLED được cập nhật theo từng hiệu ứng để sinh viên biết chương trình đang thực hiện bước nào.

6. Quy trình thực hành

  1. Kiểm tra nguồn vòng LED và nối chung GND trước khi cắm DATA D13.
  2. Nạp chương trình, quan sát lần lượt 12 điểm đỏ khi khởi động.
  3. Kiểm tra bốn trạng thái đỏ, xanh lá, xanh dương, trắng thấp.
  4. Nếu màu bị đổi, xác nhận kiểu NEO_GRB của vòng LED.

7. Bài tập mở rộng

  1. Tạo hiệu ứng điểm sáng chạy hai chiều.
  2. Quy ước xanh lá là sẵn sàng, vàng là đang chạy, đỏ là lỗi.
  3. Chỉ cập nhật NeoPixel khi màu trạng thái thay đổi.

8. Lỗi thường gặp và cách xử lý

OLED sáng nhưng NeoPixel tắt: kiểm tra nguồn riêng, GND chung và DATA D13.
Màu đỏ thành xanh: đổi thứ tự màu GRB/RGB theo loại LED.
Servo rung khi cập nhật LED liên tục: giảm số lần show() và ngắt servo khi không dùng.

9. Kết luận

NeoPixel đã được đưa vào đúng cấu hình phần cứng thay cho MPU6050 chưa đấu nối. Màu LED có thể dùng làm giao diện trạng thái ở các bài tổng hợp.
