Bài 18. Robot bám tường bằng hai laser

Bài học liên thông sử dụng cấu hình robot mới nhất và thư viện hàm dùng chung.

1. Mục tiêu bài học

  • Hiểu sai số khoảng cách giữa robot và tường.
  • Dùng điều khiển tỉ lệ P để hiệu chỉnh tốc độ hai bánh.
  • Dừng hoặc đổi hướng an toàn khi phía trước có vật cản.
Điều kiện học trước: Bài 6, 8, 9, 15 và 17.

2. Chuẩn bị

Phần cứng: Hai VL53L0X nhìn sang trái/phải, HC-SR04 phía trước, hai động cơ và OLED.

Phần mềm: Arduino IDE, board Arduino Mega or Mega 2560, Serial Monitor 115200 baud.

Trước khi biên dịch, chép thư mục THU_VIEN_ROBOT/RobotMega2560Mini vào Documents/Arduino/libraries, sau đó khởi động lại Arduino IDE. Kê hai bánh khỏi mặt đất ở lần thử đầu tiên.

3. Nguyên lý và thuật toán

  1. Đọc đồng thời khoảng cách trước, trái và phải.
  2. Chọn bám tường trái hoặc phải; lấy khoảng cách đặt trừ khoảng cách đo để tạo sai số.
  3. Nhân sai số với KP rồi cộng/trừ vào PWM hai bánh.
  4. Nếu không thấy tường, robot quay nhẹ về phía cần tìm; nếu phía trước bị chặn, robot lùi và đổi hướng.

4. Chương trình hoàn chỉnh

Chương trình sử dụng thư viện chung RobotMega2560Mini. Tải file .ino
Bai_18_Bam_tuong_hai_laser.ino
#include <Robot.h>

// BÀI 18: ROBOT BÁM TƯỜNG BẰNG LASER
// Hai laser đặt bên hông; siêu âm phía trước dùng để tránh va chạm.

const bool BAM_TUONG_TRAI = true;  // Đổi false để bám tường phải.
const uint16_t KHOANG_CACH_DAT_MM = 180;
const int PWM_CO_BAN = 120;
const int PWM_QUAY = 125;
const float KP_TUONG = 0.35f;
const float NGUONG_TRUOC_CM = 23.0f;

void hienThiBamTuong(const char *trangThai, const DuLieuKhoangCach &d) {
  oledXoa();
  oledTieuDe("BAI 18 - BAM TUONG");
  oledInChu(4, 16, trangThai);
  oledInChu(4, 30, "F:");
  if (d.sieuAmHopLe) oledInSoThuc(18, 30, d.truocCm); else oledInChu(18, 30, "NO ECHO");
  oledInChu(4, 46, "L:");
  if (d.laserTraiHopLe) oledInSo(18, 46, d.traiMm); else oledInChu(18, 46, "LOI");
  oledInChu(65, 46, "R:");
  if (d.laserPhaiHopLe) oledInSo(79, 46, d.phaiMm); else oledInChu(79, 46, "LOI");
  oledCapNhat();

  Serial.print(trangThai); Serial.print(F(" F/L/R="));
  Serial.print(d.truocCm); Serial.print('/'); Serial.print(d.traiMm);
  Serial.print('/'); Serial.println(d.phaiMm);
}

void tranhVatCanTruoc(const DuLieuKhoangCach &d) {
  dungRobot();
  hienThiBamTuong("VAT CAN PHIA TRUOC", d);
  delay(120);
  diLui(105); delay(300); dungRobot();
  if (BAM_TUONG_TRAI) quayPhaiTheoThoiGian(PWM_QUAY, 480);
  else quayTraiTheoThoiGian(PWM_QUAY, 480);
}

void setup() {
  batDauSerial();
  oledBatDau();
  dongCoBatDau();
  sieuAmBatDau();
  laserBatDau();
  oledThongBao("BAI 18 - BAM TUONG",
               BAM_TUONG_TRAI ? "BAM BEN TRAI" : "BAM BEN PHAI",
               "CHO 1 GIAY", "");
  delay(1000);
}

void loop() {
  DuLieuKhoangCach d = docBaHuong();
  if (!d.sieuAmHopLe) {
    dungRobot();
    hienThiBamTuong("DUNG - MAT ECHO", d);
  } else if (d.truocCm <= NGUONG_TRUOC_CM) {
    tranhVatCanTruoc(d);
  } else {
    bool thayTuong = bamTuongMotBuoc(BAM_TUONG_TRAI,
                                     KHOANG_CACH_DAT_MM,
                                     PWM_CO_BAN, KP_TUONG);
    hienThiBamTuong(thayTuong ? "DANG BAM TUONG" : "DANG TIM TUONG", d);
  }
  delay(80);
}

5. Phân tích chương trình

  • Hàm bamTuongMotBuoc() đóng gói thuật toán P nhưng chỉ xử lý một chu kỳ, vì vậy loop() vẫn cập nhật được OLED và cảm biến trước.
  • Giá trị KP quá nhỏ làm robot phản ứng chậm; quá lớn làm robot lắc qua lại.
  • Laser ngoài tầm không được dùng như một số đo thật; chương trình chuyển sang trạng thái tìm tường.

6. Quy trình thực hành và hiệu chỉnh

  1. Kê bánh và kiểm tra D39 đúng là laser trái, D37 đúng là laser phải.
  2. Đặt robot song song với tường ở 180 mm, chạy PWM thấp.
  3. Tăng KP từng bước 0.05 đến khi robot bám nhanh nhưng không rung.
  4. Thử cuối hành lang để kiểm tra HC-SR04 và thao tác đổi hướng.

7. Bài tập mở rộng

  1. Bổ sung thành phần D để giảm dao động.
  2. Cho phép đổi bên bám tường qua Serial Monitor.
  3. Ghi sai số và PWM ra Serial Plotter.

8. Lỗi thường gặp và cách xử lý

Robot rời xa tường: kiểm tra lại lựa chọn bên bám và chiều hiệu chỉnh.
Giá trị laser luôn lỗi: kiểm tra XSHUT D39/D37 và địa chỉ 0x30/0x31.
Robot tiến thành lùi: không thay cờ đảo chiều động cơ phải trong thư viện.

9. Kết luận

Bài 18 tạo hành vi bám tường có thể tái sử dụng cho hành lang và mê cung.
