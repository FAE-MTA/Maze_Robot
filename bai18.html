Bài 18. Giới thiệu thư viện Robot.h và cách sử dụng

Từ bài này, sinh viên chuyển từ lập trình chi tiết từng linh kiện sang gọi các hàm đã được kiểm tra trong thư viện RobotMega2560Mini.

1. Mục tiêu bài học

  • Hiểu thư viện RobotMega2560Mini giải quyết vấn đề gì.
  • Cài đúng thư viện và các thư viện phụ thuộc trong Arduino IDE.
  • Biết nhóm hàm khởi tạo, điều khiển, cảm biến và thuật toán.
  • Viết được chương trình đầu tiên dùng #include <Robot.h>.

2. Vì sao cần thư viện Robot?

Ở Bài 1–17, sinh viên nhìn thấy chi tiết khai báo chân, điều khiển PWM, đọc cảm biến và hiển thị OLED. Khi giải bài toán lớn, nếu lặp lại toàn bộ mã này thì chương trình dài và khó sửa. Thư viện gom các phần đã kiểm tra thành hàm có tên rõ ràng; chương trình chính tập trung vào trình tự và thuật toán.

Nguyên tắc: thư viện không che giấu kiến thức. Khi cần tìm hiểu sâu, mở các tệp trong thư mục src để xem cách từng hàm được cài đặt.

3. Cài đặt thư viện

  1. Mở thư mục THU_VIEN_ROBOT trong bộ website.
  2. Chép cả thư mục RobotMega2560Mini vào Documents/Arduino/libraries.
  3. Cài thêm: Adafruit GFX, SSD1306, NeoPixel, VL53L0X, BusIO và Servo.
  4. Khởi động lại Arduino IDE, chọn Arduino Mega or Mega 2560.
  5. Mở chương trình và nhấn Verify trước khi Upload.
Nếu IDE báo “Robot.h: No such file or directory”, kiểm tra không bị lồng hai thư mục giống nhau: đường dẫn đúng phải là libraries/RobotMega2560Mini/src/Robot.h.

5. Quy trình viết một chương trình dùng thư viện

  1. Thêm #include <Robot.h> ở đầu chương trình.
  2. Trong setup(), chỉ gọi hàm khởi tạo của phần cứng đang dùng.
  3. Trong loop(), gọi các hàm hành vi hoặc đọc cảm biến.
  4. Luôn có điều kiện dừng an toàn và hiển thị OLED/Serial.
  5. Các thông số PWM, ngưỡng và thời gian vẫn phải hiệu chỉnh trên robot thật.
Ví dụ: bài chỉ dùng OLED và động cơ thì cần oledBatDau() và dongCoBatDau(); không cần khởi tạo laser hoặc cảm biến màu.

6. Chương trình làm quen

Chương trình nhận lệnh T/L/A/D/S từ Serial Monitor, qua đó minh họa cách gọi hàm động cơ và OLED mà không cần viết lại phần điều khiển chân.

Tải chương trình Bài 18 (.ino)
Bai_18_Gioi_thieu_thu_vien_Robot.ino
#include <Robot.h>

// BÀI 18: LÀM QUEN VỚI THƯ VIỆN ROBOTMEGA2560MINI
// Chương trình nhận lệnh từ Serial Monitor để minh họa cách gọi hàm.
// Kê hai bánh khỏi mặt đất trong lần thử đầu tiên.
// Lệnh: T = tiến, L = lùi, A = quay trái, D = quay phải, S = dừng.

const int PWM_THU = 90;
const unsigned long THOI_GIAN_THU_MS = 500UL;

void hienThiLenh(const char *trangThai, int pwmTrai, int pwmPhai) {
  oledXoa();
  oledTieuDe("BAI 18 - THU VIEN");
  oledInChu(4, 18, trangThai);
  oledInChu(4, 34, "PWM T/P:");
  oledInSo(58, 34, pwmTrai);
  oledInSo(92, 34, pwmPhai);
  oledInChu(4, 50, "T L A D S");
  oledCapNhat();

  Serial.print(F("Trang thai=")); Serial.print(trangThai);
  Serial.print(F("  PWM trai/phai="));
  Serial.print(pwmTrai); Serial.print('/'); Serial.println(pwmPhai);
}

void chayThu(const char *trangThai, int pwmTrai, int pwmPhai) {
  dieuKhienDongCo(pwmTrai, pwmPhai);
  hienThiLenh(trangThai, pwmTrai, pwmPhai);
  delay(THOI_GIAN_THU_MS);
  dungRobot();
  hienThiLenh("DA DUNG", 0, 0);
}

void inHuongDan() {
  Serial.println(F("=== LAM QUEN THU VIEN ROBOT ==="));
  Serial.println(F("Gui T: tien  | L: lui | A: trai | D: phai | S: dung"));
}

void setup() {
  // Chỉ khởi tạo những phần cứng chương trình đang dùng.
  batDauSerial();
  oledBatDau();
  dongCoBatDau();

  // Bài này không dùng servo: giữ chân D15 ở LOW để servo không rung.
  servoNgatTinHieu();
  dungRobot();
  hienThiLenh("THU VIEN SAN SANG", 0, 0);
  inHuongDan();
}

void loop() {
  if (Serial.available() == 0) return;

  char lenh = Serial.read();
  if (lenh >= 'a' && lenh <= 'z') lenh -= 32;

  switch (lenh) {
    case 'T': chayThu("DI THANG", PWM_THU, PWM_THU); break;
    case 'L': chayThu("DI LUI", -PWM_THU, -PWM_THU); break;
    case 'A': chayThu("QUAY TRAI", -PWM_THU, PWM_THU); break;
    case 'D': chayThu("QUAY PHAI", PWM_THU, -PWM_THU); break;
    case 'S':
      dungRobot();
      hienThiLenh("DUNG THEO LENH", 0, 0);
      break;
    case '\n':
    case '\r':
      break; // Bỏ qua ký tự xuống dòng của Serial Monitor.
    default:
      Serial.println(F("Lenh khong hop le. Hay dung T, L, A, D hoac S."));
      break;
  }
}

7. Thực hành

  1. Cài thư viện, Verify chương trình trước khi nối robot.
  2. Kê hai bánh, mở Serial Monitor 115200 baud.
  3. Gửi lần lượt T, L, A, D và S; đối chiếu OLED với chuyển động.
  4. Mở RobotActuator.cpp, tìm hàm diThang() và lần theo đến dieuKhienDongCo().
  5. Đổi PWM_THU từ 90 xuống 70 và quan sát sự khác biệt.

8. Lỗi thường gặp

Robot.h không tìm thấy: chép sai thư mục hoặc chưa khởi động lại IDE.
Multiple libraries were found: xóa hoặc đổi tên bản thư viện cũ để IDE chỉ chọn một phiên bản.
Thiếu Adafruit/Servo: cài đủ thư viện phụ thuộc bằng Library Manager.
Robot chạy sai chiều: không sửa chân trực tiếp trong bài; kiểm tra RobotConfig.h và cờ MOTOR2_INVERT.

9. Kết luận
